# Contributing

Thanks for helping. Rough Cut is AGPL-3.0; contributions are accepted under the same licence.

- Setup: `pnpm install`, then `pnpm --filter @rough-cut/desktop dev`.
- Before opening a PR: `pnpm typecheck` and `pnpm test` must pass.
- UI changes: include a real screenshot of the Recording edit screen.
- Keep PRs small and focused; one change per PR.
