## Priority Issues

1. [P1] No type/spacing/radius system — the root cause. Fix: ~6 type steps, 4px spacing scale, 3 radii, 3 weights as tokens; codemod literals; collapse colours onto the surface ladder. Commands: typeset → extract.
2. [P1] Two editors, two design languages (Recording edit vs FreeCut Editor), mismatched duration/frame counts, three undo locations. Fix: theme FreeCut from shell tokens; single undo owner; reconcile duration display. Commands: extract → polish.
3. [P1] Chrome stacking (~215px before content; device row appears/disappears between views). Fix: tabs into title row, device pickers into Recorder/status chip, ≤48px chrome. Commands: layout → distill.
4. [P1] Export panel (the payoff) is the weakest composition: ragged 1/2/2/1 grid, orphan "New", inverted hierarchy, prose status. Fix: one Export + Styled/Raw segmented + Range; secondary actions in a quiet row; key/value status. Commands: layout → clarify.

6. [P2] Projects reads as a file browser: timestamp titles, colliding badges, black thumbnails, 10 toolbar controls. Command: clarify → layout.
7. [P2] Fake macOS traffic lights on Linux (decorative placeholder controls). Command: polish.
8. [P2] Timeline micro-sloppiness: uneven ruler ticks, every clip "Clip", text inside empty lanes, floating timecode, clipped bottom lanes. Command: polish.
